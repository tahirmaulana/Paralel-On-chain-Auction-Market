# PARALEL (Pasar Aset Lelang)

## Summary
PARALEL is an On-chain Auction Marketplace for Real-World Assets (RWAs), powered by Web3 technology and built on the **Arbitrum blockchain**. Currently developed as a prototype in Indonesia, PARALEL brings physical-asset auctions on-chain through transparent bidding, staking, ranking, and settlement mechanisms.

Physical asset custody and verification are handled **off-chain**, while bidding, bidder stakes, rankings, and fund settlement are executed and recorded **on-chain**. Bidder funds remain non-custodial, with smart contracts serving as the authoritative source of truth throughout the auction lifecycle.
